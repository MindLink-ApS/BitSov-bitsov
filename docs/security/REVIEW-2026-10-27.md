## Low — fixed in this PR

### L1 — The `rand` 0.8 spec still admits the unpatched 0.8.5

`deny.toml` records that `rand` 0.8.5 → 0.8.6 closed RUSTSEC-2026-0097. The workspace dependency was left at `rand = "0.8"`, which Cargo treats as `>=0.8.0, <0.9.0`. The advisory's patched range on this line is `>=0.8.6, <0.9.0`. `Cargo.lock` already resolves `rand` 0.8.6, and the transitive 0.9.3 and 0.10.3 copies are inside their patched ranges (`>=0.9.3` and `>=0.10.1`). `cargo audit` and `cargo deny` therefore report no current hit. The hole is the manifest: a resolver allowed to move inside the spec can select 0.8.5 again.

**Fix.** The workspace spec is `rand = "0.8.6"`. That is still `>=0.8.6, <0.9.0`, so a later 0.8 patch can be locked on purpose. `Cargo.lock` is unchanged. The 0.9 and 0.10 copies are not direct dependencies and are not edited.
