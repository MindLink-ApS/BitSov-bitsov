# BitSov v0.3.0-rc16 — operator signing checklist

**Pre-release.** Not for production use. rc16 = rc15 (`87b02bc`) plus the
zip advisory fix. The rc15 tag exists, but its release build was skipped
because Cargo Audit failed. rc16 is the first signed build of this content
once the checklist below is completed; this preparation does not sign or publish.

## Scope

- **Test-only zip advisory triage** (`47afad256e0ec7d1cb2ca1501428702633386081`):
  document and allow RUSTSEC-2026-0367, -0368 and -0369 in Cargo Audit,
  cargo-deny and OSV. `zip 0.6.6` remains confined to optional test harness
  build dependencies and is absent from the shipped binary. No dependency
  upgrade is included; see [the applicability analysis](../../.cargo/audit.toml).
- **`paste` warning retained:** `sqlx-core 0.8.0` pulls in `paste 1.0.15` via
  SQLx used by the node and storage crates. [RUSTSEC-2024-0436](https://rustsec.org/advisories/RUSTSEC-2024-0436.html)
  is an unmaintained warning. [SQLx 0.8.6 removes this dependency](https://github.com/launchbadge/sqlx/blob/v0.8.6/sqlx-core/Cargo.toml),
  but its [SQLite driver requires libsqlite3-sys ^0.30](https://github.com/launchbadge/sqlx/blob/v0.8.6/sqlx-sqlite/Cargo.toml),
  incompatible with vendored LDK's rusqlite 0.31 / libsqlite3-sys ^0.28.
  No small compatible upgrade is available; the warning stays visible with
  its reason in `.cargo/audit.toml` pending the SQLite dependency update (#59).

**Operator impact: none beyond rc15's notes.** No runtime, dependency, storage
format or migration changes are introduced. Pilots on rc14 upgrade directly
to rc16 using the [rc15 release notes](v0.3.0-rc15.md) and the full
[rc14 → rc15 procedure](../UPGRADING.md#rc14--rc15-procedure), substituting rc16
artifacts and version checks as explained in [rc15 → rc16](../UPGRADING.md#rc15--rc16).
The rc15 rollback rule remains in force: **no downgrade to rc14 after running
rc16 with embedded LDK**. Preserve the latest state and roll forward; the
reviewed startup cutoffs and narrow pre-storage failed-start exception are
unchanged.
