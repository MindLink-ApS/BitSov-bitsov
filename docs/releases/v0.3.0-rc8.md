# BitSov v0.3.0-rc8 — release notes (paste into GitHub)

**Pre-release.** Not for production use. Describes what is built; nothing here is a supported platform claim.

**Status:** notes prepared on branch `release/v0.3.0-rc8`. Do **not** treat this file as a published release until the annotated tag exists, CI has staged draft assets, `SHA256SUMS.asc` is attached, and an operator publishes the pre-release.

## Why upgrade from rc7

rc7 fixed startup probe / TLS issues. Everything the app still cannot ship while pinned to rc7 — scoped pairing, budget grants, not_dispatched payment refusals, exactly-once compose, BOOT-2 readiness, front door, paid calls signalling, and the retained-node upgrade path — landed on `main` afterward. rc8 is the signed cut of that line so bitsov-app can leave `v0.3.0-rc7`.

Retained nodes: read [`docs/UPGRADING.md`](../UPGRADING.md) **before** replacing the binary (`NODE_INITIALIZED` repair; stale `KONSENSUS_SQLITE_MIGRATIONS_DIR`; migrations **026–028**; `[pricing] call_msat`; MSRV **1.88**).

## What's in rc8

### Payments safety
- Proven non-dispatch is preserved end-to-end as HTTP `400` with `code: "not_dispatched"` (#115, #117), including capped re-admission refusals with a stable reason (#121).
- **Quoted capped re-admission** is generation-bound: the payer's quote and the recipient's generation must match (#127, revived from #111).
- Admission **fee ceilings are reported only at wallet dispatch** (#128).
- Invoice timestamp checks **tolerate small recipient clock skew** (#126).
- All-in Lightning caps cover principal and routing fees (#99); paid-send caps are node-enforced (#80).
- Incomplete paid recovery fails closed to `payment_unknown` (#119); paid resends back off while the peer is offline (#118); outbox recovery scans are bounded with replay tombstones (#116).
- Paid envelopes stay until atomic acceptance ACK (#103).

### Calls (regtest prototype)
- Paid **1:1 call signalling**, kinds **400–403** (#131). Call state and admission holds persist across restarts (migrations **027**, **028**). See [`docs/v2/CALLS-PROTOTYPE.md`](../v2/CALLS-PROTOTYPE.md).
- Configure `[pricing] call_msat` (default **10 000** msat; must be **> 0**) for the offer (kind 400). Answers, ICE, and hangup use `realtime_signal_msat`.
- **STUN is app-side only:** the owner optionally sets a `stun:host[:port]` in Settings. The node never embeds a STUN/TURN server; no TURN relay. Without STUN, calls use host candidates (same network / VPN).

### Web services (paid porch)
- `KIND_WEB_MANIFEST` / `KIND_PAGE_RESPONSE` **replies bind to the requester's paid proof** — no self-minted Lightning proofs (#129).
- Outstanding paid 500/510 requests are recorded in a **durable table** (migration **026**) and expired rows are swept (#132).
- Unbound zero-amount 501/510 still hit the Mock price floor; replies are never routed as requests.

### Front door
- **FrontDoorCard v1**: signed doorstep card (≤16 KiB, seq, 7-day expiry), Admin PUT / Read GET+verify+open, `front_door_v1` capability (#130). Knock stays existing first contact; doorstep is free to carry.
- Seq floor + identity check + fail-closed verify without a Bitcoin network (#133); adopted seq floor capped so a hand-edited `u64::MAX` cannot lock publish (#135).

### Owner / CLI
- `konsensus sign-challenge` matches the `/auth/token` challenge format used by owner-token flows (#125).

### Demo / honesty
- One-command **regtest rehearsal** for local demos (#122); **rehearsal v2** adds front-door, voice-note, and 1:1 call beats (#134).
- **No mock-proof profile** envelope on real Lightning backends (#123).

### Exactly-once
- Persisted compose operations (#113) and event-driven settlement (#108).
- Instant paid first contact and payer-side reply acceptance (#102, #100).

### Readiness
- Local API remains available while Lightning recovers (#107); LDK fee-fetch startup retries with bounded backoff (#98).
- Freshness headers on pinned reads (#78/#79/#84); energy and membrane organism reads (#82, #96, #97).

### Upgrade path
- Stale on-disk migrations directories are refused (#120); embedded set through **028** (026 web requests; 027 call state; 028 call admission hold).
- Pre-bootstrap nodes get an explicit `konsensus repair mark-initialized` path (#120, #76/#77).
- Pairing bootstrap, owner CLI approvals, and route scopes (#72/#73, #76/#77, #92).
- **MSRV 1.88** (#128 / workspace `rust-version`).

### Dependencies
- Workspace version `0.3.0-rc8`; `base64` 0.23.1, `mockall` 0.15.0, rust minor/patch group (#46, #47, #88).

## Known limits in this release
- **macOS and Windows binaries are not notarized or Authenticode-signed.** Covered by signed `SHA256SUMS` only; Gatekeeper/SmartScreen will block by default.
- **Startup selection is not continuous runtime failover** for chain providers (rc7 posture unchanged).
- **sqlx 0.8.0 island** still pinned by ldk-node; see `.cargo/audit.toml` / #59.
- **Calls** are a regtest prototype: signalling is paid; media is direct WebRTC; no TURN; STUN is optional and owner-chosen.
- **Front door** porch fetch and paid porch pages remain phase 2; Knock uses first contact only.
